# Skill: toolbox-browser-feature-designer

This skill provides specialized design requirements for the Vault Toolbox Browser Extension to ensure UI consistency and accessibility.

## 1. Tool Visibility
The design document MUST explicitly address:
- Menu Bar: How the tool is launchable from the application menu bar.
- Settings: The presence of an ON/OFF toggle in the Settings page.

## 2. Mandatory DoD Items (Toolbox Browser)
1. Tool must be launchable from the sidebar/menu.
2. Tool must have an ON/OFF toggle in Settings.
3. Production Protection: Modifying operations must be disabled in Production with a tooltip message.
